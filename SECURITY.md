# Security Policy

Do not report security vulnerabilities through public GitHub issues.

- Email the maintainer with: affected version/commit, repro steps, impact, and (if any) a fix sketch.
- Expect acknowledgement within 72 hours and coordinated disclosure before any public note.
- Scope: this repo's API, SPA, auth/session handling, and data pipeline. Out of scope: Gemini-side behavior, Neon/Vercel platform issues (report those upstream).

Details: [`docs/SECURITY.md`](docs/SECURITY.md).
